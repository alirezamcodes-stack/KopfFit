# KopfFit

## Projektbeschreibung

KopfFit ist ein geplantes Gruppenprojekt im Rahmen des Unterrichts.

Die Idee ist eine seniorenfreundliche Quiz-Webanwendung für Alten- und Pflegeheime. Die Anwendung soll ältere Menschen durch einfache Quizfragen aktivieren, Gedächtnistraining unterstützen und gemeinsame Aktivitäten ermöglichen.

Der Fokus liegt auf einer einfachen Bedienung, gut lesbarer Oberfläche und einer klaren Struktur.

---

## Geplantes MVP

Die erste Version soll bewusst einfach gehalten werden und folgende Grundfunktionen enthalten:

- Startseite
- Kategorieauswahl
- Quizfragen mit Antwortmöglichkeiten
- Punktesystem
- Ergebnisanzeige

Weitere Funktionen werden erst nach der Grundversion geplant.
